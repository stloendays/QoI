# Cross-domain QSQ generality — JHTDB turbulence protocol (2026-10-01)

Status: **author-authorized independent generality experiment; protocol frozen before outcome inspection.**

This package tests whether QoI Stability Qualification (QSQ), defined on a complete scientific measurement contract, transfers from electronic-density analysis to a physically and numerically distinct domain: three-component turbulent velocity fields.

No manuscript claim is changed by this package until the pre-declared analyses are complete and audited.

## Scientific question

Does a five-probe QSQ screen prospectively stratify unseen downstream-response risk for derivative-based turbulence quantities computed from a vector velocity field?

The experiment intentionally changes all three of the following relative to the electronic-density benchmark:

- scientific domain: electronic structure -> turbulence / CFD;
- primary stored object: scalar density -> three-component velocity vector field;
- downstream structure: basin partition / electrostatics -> spatial differentiation followed by quadratic and threshold operations.

## Public source

Johns Hopkins Turbulence Database (JHTDB), forced isotropic turbulence dataset `isotropic1024coarse`.

The source DNS uses a periodic `1024^3` grid. Velocity is sampled at exact grid locations through the current JHTDB Python/REST interface. The JHTDB public testing token is used only for requests within its published small-query limit, one query at a time.

## Pilot population

Primary pilot: **64 independent cutouts**, each `15 x 15 x 15` grid points (3,375 velocity vectors, below the public testing-token 4,096-point request limit).

The usable derivative domain is the interior `13^3 = 2,197` voxels. No periodic wrapping is assumed across a cutout boundary.

Sampling is deterministic and outcome-blind. A manifest generator uses SHA-256 over `"QSQ-JHTDB-20261001|sample_index"` to select:

- one stored coarse-frame index in the stationary interval;
- integer x/y/z origins such that all 15 points remain inside the `1024^3` domain.

Duplicate time-origin keys are forbidden. The frozen manifest is written before any downstream QSQ outcome is evaluated.

## Reference numerical algorithm

Grid spacing:

[
\Delta x = 2\pi / 1024.
]

For each interior voxel, the velocity-gradient tensor is computed from second-order centered differences,

[
A_{ij}=\partial_j u_i.
]

Define

[
S=\frac{A+A^T}{2},\qquad
\Omega=\frac{A-A^T}{2},
]

and the Q criterion

[
Q=\frac12(\|\Omega\|_F^2-\|S\|_F^2).
]

Vorticity is

[
\boldsymbol\omega=\nabla\times\mathbf u.
]

The reference enstrophy-density summary is

[
E=\langle |\boldsymbol\omega|^2\rangle
]

over the `13^3` interior voxels.

For the thresholded-vortex endpoint, the reference threshold is frozen per cutout as the 90th percentile of the exact reference-Q values,

[
\theta_Q=P_{90}[Q].
]

The exact reference mask is

[
M(\mathbf r)=1[Q(\mathbf r)>\theta_Q].
]

The threshold `theta_Q` is an exact derived reference parameter and is not recomputed after perturbation.

## Declared approximate-input scale

The velocity field is the sole approximate input.

For cutout `m`, the QSQ amplitude is the exact float16 round-trip L-infinity scale of the downloaded reference velocity:

[
\epsilon_m =
\|\mathrm{float16}(\mathbf u_m)-\mathbf u_m\|_\infty.
]

This defines a reduced-precision-like input-handling contract without making eligibility codec-specific.

Each perturbation is iid uniform in every velocity component and grid point:

[
\delta_{m,s}\sim U(-\epsilon_m,+\epsilon_m).
]

The QSQ seed labels are the same canonical five labels used elsewhere:

`20260905, 1, 2, 3, 4`.

Deterministic PCG64 stream seeds are generated by SHA-256 over the scientific sample key, QoI family and seed label.

## QoI response metrics

### Primary: vortex-mask fidelity

For a perturbed field, recompute the velocity gradient and Q field, then apply the **frozen exact-reference threshold** `theta_Q`.

Response:

[
r_M = 1-\mathrm{IoU}(M,\widetilde M).
]

Pre-declared thresholds:

[
\tau_M\in\{0.01,0.05,0.10\},
]

with **0.05 primary**.

### Secondary: enstrophy fidelity

Response:

[
r_E = |\widetilde E-E|/E.
]

Pre-declared thresholds:

[
\tau_E\in\{10^{-3},10^{-2},5\times10^{-2}\},
]

with **0.01 primary**.

## QSQ rule

For QoI `q` and cutout `m`,

[
f_{m,q}=\max_{s\in S_5}r_{m,q,s}.
]

The cutout-QoI contract is QSQ-eligible at tolerance `tau_q` iff

[
f_{m,q}<\tau_q.
]

All five qualification probes are retained in this experiment because the numerical floor itself is an analysis endpoint.

## Prospective validation

After the five-seed QSQ state is frozen, evaluate **59 fresh perturbations per cutout** using seed labels `10000..10058`, the same amplitude, reference threshold, numerical algorithm and response definitions.

Primary comparison:

[
P(r\ge\tau\mid\mathrm{QSQ\ eligible})
\quad\text{vs}\quad
P(r\ge\tau\mid\mathrm{QSQ\ rejected}).
]

Report:

- trial-level exceedance risk;
- material/cutout-cluster bootstrap 95% intervals;
- rejected-to-eligible risk ratio;
- fraction of cutouts with at least one fresh exceedance;
- QSQ coverage.

No threshold, perturbation amplitude or QoI definition is retuned after observing fresh outcomes.

## Cross-QoI generality

Compare primary-threshold QSQ eligibility for vortex-mask fidelity and enstrophy using:

- raw agreement;
- Cohen's kappa;
- Spearman correlation between measured floors.

This tests whether the qualification principle transfers while the evaluability boundary remains QoI-specific.

## Differential-operator mechanism audit

A pre-declared supporting audit measures amplification of perturbation energy by differentiation.

For each qualification perturbation, record

[
A_{\nabla}=
\frac{\|\nabla\delta\mathbf u\|_2}
{\|\delta\mathbf u\|_2}.
]

In Fourier language, differentiation weights a mode by its wavenumber. The audit therefore tests the operator-level contrast with the Hartree mechanism, where the Poisson operator preferentially amplifies low-wavenumber error.

No claim of universal high-frequency dominance is made unless directly supported by the observed perturbation spectra and downstream responses.

## Primary acceptance rule for cross-domain generality

The statement

> QSQ prospectively stratifies downstream-response risk in a derivative-based turbulence measurement contract

is supported only if, for the primary vortex-mask endpoint at `tau_M=0.05`:

1. at least 10 of 64 cutouts are eligible and at least 10 are rejected;
2. fresh rejected-to-eligible exceedance risk ratio is at least 5;
3. the cutout-cluster bootstrap 95% interval for the risk difference excludes zero.

If criterion 1 fails because the pre-declared threshold yields insufficient coverage balance, the result is reported as non-discriminating at that threshold; no post hoc threshold is substituted. Secondary pre-declared thresholds may be reported descriptively.

A stronger generality statement requires the same directional risk separation for enstrophy at its primary threshold.

## Scaling rule

The 15-cube public-token experiment is a formal pilot, not a substitute for a production-size turbulence benchmark.

If the primary acceptance rule is met, the protocol may be scaled without changing scientific definitions to larger `64^3` or `128^3` cutouts after obtaining a full JHTDB/SciServer authorization path. The larger run will be treated as confirmatory and will not use pilot outcomes to retune thresholds.
