# QSQ optimization extension — pre-declared protocol (2026-10-01)

Author-authorized reopening for optimization of the deployed QoI Stability Qualification (QSQ) procedure. The frozen five-seed QSQ definition used by the current manuscript is preserved unchanged as the scientific benchmark. This extension tests whether the same qualification semantics can be made cheaper and whether the perturbation target should be defined by the actual measurement contract.

The extension starts from branch `ext/WP-EFG-20260930`. It writes only under `analysis/extensions_20261001/` until an explicit manuscript-integration decision is made.

## Shared rules

- The current five-seed QSQ result remains the reference classification.
- No current manuscript threshold, cohort, endpoint, figure, or certification result is rewritten by this extension.
- All denominators include recorded failures; failures are never converted to passes.
- Reader-facing claims are allowed only after the corresponding result is complete and audited.
- Internal optimization may reduce computation but must not silently redefine the scientific contract.

## WP-H — Exact sequential early-rejection QSQ

### Question

Can the existing five-seed binary QSQ decision be reproduced exactly while avoiding probe solves that cannot change the final decision?

### Frozen inputs

`stability/stability_floor_A1_per_seed.csv` for the 254 development materials only (`corpus` beginning with `dev_`). The existing seed order is retained exactly:

`20260905, 1, 2, 3, 4`.

The response for a seed is `floor_noise_resolved_e`. Thresholds are the current manuscript thresholds:

`tau in {1e-4, 1e-3, 1e-2} e`, with `1e-3 e` primary.

### Sequential rule

For a material and threshold `tau`:

1. Compute the reference Bader result once.
2. Evaluate the five frozen QSQ seeds in the frozen order.
3. Stop immediately when any observed response is `>= tau`; the material is rejected because the final five-seed maximum must also be `>= tau`.
4. If all five responses are `< tau`, the material is eligible.

This rule is mathematically required to reproduce the frozen five-seed binary classification exactly; it is not a statistical approximation.

### Metrics

For each threshold:

- exact agreement with the frozen five-seed eligibility decision;
- mean and median number of probe solves per material;
- mean total Bader solves per material including one reference solve;
- fraction of probe solves avoided relative to five probes for every material;
- fraction rejected after seed 1, seed 2, seed 3, seed 4, or only after seed 5;
- the same cost metrics separately for frozen-eligible and frozen-rejected materials.

### Acceptance

WP-H is adopted as the default implementation optimization if:

1. eligibility agreement is exactly 254/254 at every threshold; and
2. the mean number of probe solves at the primary `1e-3 e` threshold is < 4.0 per material (>=20% probe-solve reduction).

If criterion 2 is not met, the result is reported but the frozen implementation remains unchanged.

No seed reordering is optimized after seeing outcomes. Any alternative ordering is exploratory only and cannot be used for the acceptance result.

### Outputs

`WP-H/sequential_material.csv`, `WP-H/sequential_summary.csv`, `WP-H/RESULTS.md`, `WP-H/provenance.json`.

## WP-I — Partition-reference-only sensitivity decomposition

### Question

WP-G showed that Bader qualification is nearly eliminated when the all-electron partition-defining reference is kept exact (G1), but becomes severe when both CHGCAR and the all-electron reference are perturbed (G2). Is the G2 instability primarily generated by perturbing the partition-defining all-electron reference itself?

### Population

The same 53 Materials Project development materials pre-declared for WP-G. The three materials with non-finite published AECCAR0 remain explicit input failures. Primary paired analyses therefore use the 50 analyzable materials and also report the conservative 53-material denominator.

### Measurement semantics

Use the same Henkelman Bader 1.05 on-grid implementation and settings used for the completed WP-G analysis:

`-b ongrid -vac 0.001`.

Reference charges use exact CHGCAR integrated over basins defined by exact `AECCAR0 + AECCAR2`.

### New arm G3: all-electron reference perturbed only

For each frozen QSQ seed:

- CHGCAR is held exact.
- The all-electron reference `rho_AE = AECCAR0 + AECCAR2` is perturbed at its own float32 amplitude `epsilon_AE`.
- Use exactly the WP-G reference perturbation seed mapping:
  first 8 bytes (little-endian) of SHA-256(`"QSQ-WPG|material_id|seed"`).
- Recompute Bader charges and basin labels.
- Define `f_m^G3` as the maximum absolute per-atom charge response over the five seeds.

### Primary analyses

At each `tau in {1e-4, 1e-3, 1e-2} e`:

1. Eligibility under G3.
2. Paired eligibility comparison G3 versus G1 and G2.
3. Material-wise floor comparison:
   `log10(f_G3 / f_G2)` and `log10(f_G3 / f_G1)`.
4. Basin-reassignment fraction for G3 versus G1 and G2 on the same five probe seeds.
5. Mechanism attribution:
   fraction of materials for which `f_G3 >= 0.5 f_G2` and `f_G3 >= 0.9 f_G2`.

### Acceptance

The statement

> perturbation of the partition-defining all-electron reference is the dominant source of the observed G2 QSQ instability

is supported only if, at `tau = 1e-3 e`:

1. G3 leaves at least 80% of analyzable materials non-evaluable; and
2. the material-median `f_G3 / f_G2` is >= 0.5; and
3. the median G3 basin-reassignment fraction is at least 50% of the G2 median.

Otherwise the result is reported descriptively without the dominance claim.

### Computational scope

WP-I requires only the reference solve plus five G3 probe solves per analyzable material. No codec ladder is rerun. Existing WP-G CHGCAR, AECCAR, and baseline reference inputs are reused after SHA verification.

### Outputs

`WP-I/reference_only_probes.csv`, `WP-I/material_summary.csv`, `WP-I/summary.csv`, `WP-I/failures.csv`, `WP-I/RESULTS.md`, `WP-I/provenance.json`.

## Interpretation lock

Even if WP-H and WP-I succeed:

- WP-H is an implementation optimization of the existing binary QSQ decision, not a new scientific eligibility definition.
- WP-I may refine the Bader mechanism and the definition of the measurement contract, but it does not retroactively invalidate the frozen valence-reference benchmark.
- QSQ remains codec-independent.
- Continuous risk calibration remains Discussion/SI evidence and does not replace binary eligibility.
- Any future boundary-escalation scheme using more than five probes requires a separate prospective protocol before it can alter certification semantics.
