# Manuscript figure drafts

## Status

These are **scientific-content drafts**, not publication-ready artwork. The first pass prioritizes data integrity, panel logic, and manuscript narrative. Typography, spacing, annotation density, and final journal styling will be redesigned after the full figure set is assembled.

## Frozen design principle

Do not infer chemical fidelity from pointwise error bounds alone. All headline certification results must use the frozen Protocol A.1 eligibility semantics and resolved-basin downstream error where specified.
