# QoI / RhoCodec

This repository is an intentionally minimal public placeholder for an active, unpublished research project.

The manuscript, benchmark datasets, figures, supplementary information, validation outputs, analysis records, experimental protocols, and submission materials are **not distributed publicly before publication**.

Public GitHub content must not be treated as the authoritative source for unpublished scientific results or submission text. Authorized collaborators and Agents should use the project's private research workspace and internal project status records.

Do not restore unpublished research assets, numerical result tables, manuscript drafts, or submission figures to the public repository until an explicit release decision has been made.
