## Important distinction

`Public PDF link only` does **not** mean the work is unavailable. It means a lawful public source was recorded but the remote PDF was not copied into Notion automatically, typically because the source file exceeded the current remote-import cap or the hosting site rejected server-side retrieval. These entries remain one-click accessible from the database and can be attached manually later without changing the canonical citation list.
